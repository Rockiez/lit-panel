## v0.2.0（veto 判据分级 + 席02微观连续性扩充 + 席位重叠一次性审计）

### veto 判据分级（文学带核心席 04/05/06/07/09）

在既有 core/extended 二层之上，从五席核心判据表内各自划出 ≤2 条升格为 **veto** 层——veto 是 core 判据中最不可辩护、命中即代表该维度结构性坍塌的子集（选择标准：不是最常用的判据，是命中后果最致命的判据）。带位后果差异见各文件"veto 判据表"标注、SKILL.md §5.3。逐席选择与理由：

- **席04（结构）→ N2（无因之果）**：候选还包括 N1（被遗弃的情节承诺）与 N4（流水账式罗列，缺"动机-阻碍-行动-结果"循环），但 N2"重大结果无铺垫无解释"是叙事因果链最基础的断裂点——读者连"为什么会这样"都无法理解，比"某条线索没收尾"（N1）或"叙事引擎偏弱"（N4）更直接摧毁对整篇叙事逻辑的信任。只选 1 条，未凑满 2 条上限。
- **席05（人物）→ P1（行动/动机与既定处境性格一致）**：候选还包括 P5（拒绝粉饰）与 P3（抽象概括代替具体细节），但 P1 是人物写作的地基——一旦某个行动/动机毫无触发点地偏离既定性格，读者会对文本里**所有**人物刻画的可信度产生连锁怀疑，而 P5/P3 更多是深度/技法问题，不会牵连全篇。只选 1 条。
- **席06（语言）→ L1（声音/语域随场景解释）**：候选还包括 L2（词汇句法变化需意图），但 L1（语调/人物声音无来由的突变）比 L2（词汇句法层面的拼接感）更容易让读者直接察觉"这是谁在说话"的错乱，是声音一致性里最先失控、也最难挽回的一层。只选 1 条。
- **席07（情感）→ E1（情绪由行动/对白/环境承载）+ E2（拒绝情感硬推）**：本席是唯一选满 2 条的核心席——E1（情绪完全没被戏剧化，只被叙述者宣布）与 E2（情绪被强行戏剧化到失真）恰好是"processed vs lived"这一失败空间的两个对称极端，且本席自己的席位定位一句话（"processed vs lived 的平衡、避免情感硬推"）本就同时点名了这两端，任一极端命中都代表本章情感处理从根本上失败，两条缺一不足以覆盖整个失败面。
- **席09（原创性）→ O1（拒绝被用滥的比喻/场景模板/感悟句式）**：候选还包括 O2（独特见解）与 O3（转折意外合理），但 O1 命中意味着"这段话可能出自任何一篇同类文本"，直接击穿"原创"这个维度的存在理由；O2 关乎见解的**价值**而非表达的**新鲜度**，O3 关乎情节机关（且与 TW8 有交叠，见下方重叠审计），严重度都不如 O1 直接。只选 1 条。

各席 veto 表结构：独立的"## veto 判据表"小节，位于该文件"## core 判据表"之前；对应的 core 表已移除这些行。判定提示同步补充"veto 判据"专款说明严重度分档逻辑，并把原"core 判据任一 NO 即封顶 C"改写为"其余 core 判据任一 NO 最高封顶 B"。

**补记（修正范围声明）**：本节最初提交时的"同步完成"表述有误——veto 分级落地时只改动了 `skills/lit-panel/references/criteria/04-09-*.md` 五个**判据文件**，对应的 `agents/{structure,character,prose,resonance,originality}-reviewer.md` 五个**席位人设文件**当时仍停留在 v0.1 表述（"core 判据任一 NO 会使文学带封顶 C"），其中 `structure-reviewer.md` 还残留了已废弃的"席08 体验报告正向"从句。这一遗漏在后续一轮全链核查中发现并补齐：五个 agents 文件的带位描述已改写为 veto/core 两层口径，逐席点出各自的 veto id；`structure-reviewer.md` 的过期从句已删除。记录于此，作为"声明同步完成前，需要同时核对 criteria 与 agents 两侧文件"这条经验的存档。

### 席02 微观连续性扩充（C8、C9）

新增两条 extended 判据，均已同步补入 `docs/criteria-pool.md` 席02节：

- **C8** [风险] 同一场景内动作或物件状态出现无解释的跳变（如放下的物件又在手中、湿衣未干先干）—— ConStory·外观/数量不匹配【已核实·转译】。既有 C1-C7 覆盖的是跨段落/跨场景的宏观一致性（日期、地点、记忆），C8 补上同一场景**内部**的微观物理连续性缺口，这是既有判据集合此前完全没有覆盖的一类真实错误。
- **C9** [风险] 描写违反基本生活常识或该时代物质条件，且无文本解释 —— 【自研】（无源场景下的常识合理性检查）。补上"没有 --source 时也能做的最低限度真实性检查"——忠实带在无 source 时整体记 N/A，但明显违反常识/时代物质条件的描写不该因此彻底失去检验，C9 用一致性审读的框架（而非来源核对）兜住这一类。
