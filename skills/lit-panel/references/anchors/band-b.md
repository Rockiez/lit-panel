# 带位锚例 · Band B（合格但"平" —— processed 而非 lived）

> **纯合成声明**：本文人物、机构、地名、事件均为虚构，不取材、不影射任何真实访谈素材。仅用于校准席 04/05/06/07/09「文学带」与席 08「素读者」的带位判断。判据 id 引自 `docs/criteria-pool.md`（构建期取材来源，判据 id 定义以分发包内 `criteria/*.md` 为准）。
>
> 本文与 `band-a.md` 共用同一个虚构场景（顾雪梅、周厚生、1963 年冬顾雪梅师傅调离），细节数字（进厂年数等）各篇独立设定、各自内部自洽，不要求跨篇数字一致——三篇是"同一类场景的三种写法"，不是同一份手稿的三个版本。

## 合成回忆录片段

1963年腊月的一个晚上，周厚生照常来车间上最后一个夜班——厂里已经通知他，过完年就要调去邻县的农具厂。顾雪梅那时进厂三年，接头的手艺是他一点点教出来的。这天晚上他比平时话多一些，把车间的几台车都仔细看了一遍，又检查了顾雪梅接的纱锭，说她这一年长进不少，以后要多用心，把手艺继续练扎实。临走前，周厚生还把自己用了多年的几件小工具留给了她，叮嘱她以后遇到解决不了的问题，就照着老办法多琢磨琢磨。顾雪梅心里挺不是滋味，嘴上却没说什么，只是点了点头。这些年跟着师傅学手艺的日子，后来常被她想起，成了她心里一直很珍惜的一段回忆。第二天，车间照常开工，周厚生的工位换了新人，一切像往常一样运转起来。往后的日子里，顾雪梅也带过几个徒弟，教法大体上还是当年周厚生教她的那一套。

（正文 331 字）

## 为什么是这个带位

**带位结论：B（合格，不进 A 候选，也不封顶 C）。** 这是三个带位里最难写、也最难判的一个——它不靠一条清楚的判据 NO 把自己摁下去，而是**几乎每一条都压线通过**。核心判据中 E1/P4/L4 三条属于压线判断（逐条理由见下表与判定说明），其余多数也是弱通过而非清楚通过——这正是"平"的诊断难点，也是这个锚例存在的意义：证明带位判断不能只做判据表机械勾选。

### 第一步：为什么不是 C —— 核心判据没有一条构成清楚、可无异议引证的 NO

**E1 判定说明**：判 YES 而不是 NO 的依据是——这句话里确实存在"点了点头""嘴上却没说什么"两个可观察的行为载体，不是纯粹的"她很难过"式断言；对比 band-c 里情绪**完全**由叙述者宣布（"泪水在她眼眶里决堤"），本篇至少还有动作的骨架。但评审必须承认这是压线判断，不是清楚判断——这正是 B 带位难判的真实写照，写这条锚例时特意保留这个争议，而不是把它写"干净"，因为真实评审工作里这类边界案例远比一目了然的 A 或 C 常见。

### 席 03（A 系列，证据，无否决权）

A1 命中一处（"成了她心里一直很珍惜的一段回忆"可整句删除，见 `slop-patterns-zh.md` 密度维）；A2 轻微命中（"临走前……叮嘱她……"这类过渡带一点模板感，但未到密集程度）；A6 轻微命中（"心里挺不是滋味"处有一点点脱离具体位置的泛化倾向）。命中数量和严重度都明显低于 `band-c.md`，仅作证据参考，不改变带位。

### 席 08（素读者，后测预期）

预期为**不构成清楚正向**：读者大概率能复述情节（"师傅要调走了，教了她最后一次，还留了工具"），但被追问"哪一段让你记住了"时，答案会含糊、给的是整体印象而非具体画面；R1/R4 大概率给出弱回答而非清楚的肯定回答。**这才是机械规则里"其余 → B"的真实触发点：不是某条判据判了 NO 把它摁下去，是没有任何一条判据、任何一处细节强到能把它抬进 A。**

### 这个锚例要防的两种误判

1. 只看判据表、找不出一条硬伤，就把它误判成 A——这是把"没有清楚的 NO"等同于"优秀"，忽略了 extended 项和素读者反应才是区分 B/A 的关键。
2. 因为 E1/P4/L4/TW7 读起来单薄就把它争论成 C——这是把"弱执行"等同于"核心判据破功"，混淆了"平"和"坏"的区别；`band-c.md` 展示的才是真正的核心破功。

### 与其他带位的对照点

同一个"临走留物件"的动作，band-a 具体到"磨得发白的铜制接头钩""胶布边缘卷了毛边"；本篇是"几件小工具"——这是 P7"独特细节 vs 可替换装饰"最直接的对照。同一个"心里的感受"，band-a 完全不写、靠动作传递；本篇写了一句"心里挺不是滋味"又立刻收住；band-c 写成"泪水在她眼眶里决堤""命运对这个善良女孩最残忍的一次捉弄"——三篇连起来看，正好是 E1/E2 从"克制"到"压线"到"失控"的完整光谱。
