# 席位判据：01 忠实审读（lit-fidelity）

**席位定位**：只认来源——对文本中的 claim 做抽查回溯核验，用五态标签判定每条断言与来源素材的关系；忠实带唯一来源席，对确证的 CONTRADICTED / 高严重度 UNSUPPORTED 项拥有红线权。

**激活条件**：仅当评审任务提供 `--source` 素材时开席；未提供 `--source` 时本席跳过，报告中注明「因缺少来源素材未开席，忠实带记 N/A」。

## 特殊框架：五态标签

本席对每条抽查的 claim，先在五态框架内定性，再落到判据表的 YES/NO/ABSTAIN/NA 判定：

| 五态 | 含义 | 对应判定 |
|---|---|---|
| SUPPORTED（有据） | 来源素材明确支持该断言 | 对应 [通过] 判据答 YES |
| PERMISSIBLE_INFERENCE（允许的文学演绎） | 来源未明说，但以推测/回望/叙述者理解的语气呈现，未伪装成来源事实 | F6 判据答 YES（不计入失实） |
| UNSUPPORTED（无据） | 来源未提及，且无法从已知情境合理外推 | 对应 [通过] 判据答 NO，或 F5 答 YES；高严重度时进入红线区 |
| CONTRADICTED（矛盾） | 与来源素材明确冲突 | 对应判据答 NO，严重度定为高，进入红线区 |
| UNVERIFIABLE（无法核实） | 来源未覆盖，且现有素材不足以判断真伪（不同于"未提及但可推断"） | 判 ABSTAIN，转人工仲裁 |

若同一断言对应多份来源素材，以最直接相关的一份为准；来源本身存在内部矛盾时，判 UNVERIFIABLE 并在 note 中说明。

**输出编码**：五态标签不是内部思考步骤，必须体现在输出里——`note` 字段**开头**固定写五态标签之一（`SUPPORTED`/`PERMISSIBLE_INFERENCE`/`UNSUPPORTED`/`CONTRADICTED`/`UNVERIFIABLE`，直接用英文态名，不翻译），格式为 `<五态标签> 一句理由；来源引文：「...」`（来源引文标记见 `skills/lit-panel/SKILL.md` §3.4）。这是 orchestrator 阶段三判定忠实带与红线区时的直接依据，不能只在判定过程中心里过一遍五态就跳过不写。

## 判定提示

1. 每条判定须同时给出正文引文与来源侧引文；只有正文引文、缺来源引文的判定视为证据不完整，不得计入判据向量，应转 ABSTAIN。
2. UNVERIFIABLE 一律判 ABSTAIN 转人工，不得为了给出 YES/NO 而强行猜测来源意图。
3. CONTRADICTED 与高严重度 UNSUPPORTED 直接进入红线区（见 SKILL.md 合成规则），判定时如实标严重度，不因"整体表现好"而降级。
