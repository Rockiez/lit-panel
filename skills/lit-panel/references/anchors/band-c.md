# 带位锚例 · Band C（核心判据破功）

> **纯合成声明**：本文人物、机构、地名、事件均为虚构，不取材、不影射任何真实访谈素材。仅用于校准席 04/05/06/07「文学带」与席 08「素读者」的带位判断（席09原创性 v0.4.1 起退出带位体系，改走独立的"原创加分"，本文中 O1 仅作佐证参考，不承担带位判定角色），同时演示席 02 一致性红线与席 03 证据向量如何与带位判断并行、互相印证。判据 id 引自 `docs/criteria-pool.md`（构建期取材来源，判据 id 定义以分发包内 `criteria/*.md` 为准）。
>
> 本文与 `band-a.md`、`band-b.md` 共用同一个虚构场景（顾雪梅、周厚生、1963 年冬顾雪梅师傅调离）；本篇按要求刻意植入三类缺陷各一处：**情感硬推**、**套话密集**、**时间线矛盾**，并在下方逐一点名引证。

## 合成回忆录片段

岁月如歌，时光荏苒。在那个物质匮乏的年代，顾雪梅的命运就像车间里永不停转的纱锭，被时代的洪流裹挟着向前。1963年，十六岁的她刚刚踏入纺织厂的大门，车间里的周厚生便成了她人生画卷中最浓墨重彩的一笔。三年后，当周厚生因为家庭成分问题被下放到邻县农具厂的那个寒冷冬夜，顾雪梅的心仿佛被狠狠揪了一下——不，应该说，这不仅仅是一次普通的离别，而是命运对这个善良女孩最残忍的一次捉弄。那一刻，泪水在她眼眶里决堤，她终于明白，人生就是一场又一场猝不及防的告别。值得注意的是，周厚生在临走前，依然像四年前她刚进厂第一天那样，手把手地教她接线头，仿佛要把毕生所学都倾囊相授。总的来说，这段师徒情谊，不仅是技艺的传承，更是一曲关于坚韧与温暖的时代赞歌，奏响了那个特殊年代里普通人相互扶持的动人序曲。

（正文 340 字）

## 为什么是这个带位

**带位结论：C（核心判据破功），且同时触发席 02 红线区。** 这是三个带位里最不该有争议的一个——设计目标就是让每一类缺陷都有一处无异议的引证，不留压线空间。

### 时间线矛盾（触发席 02 红线，高严重度确证矛盾）

三处引文放在一起看：

1. "1963年，十六岁的她刚刚踏入纺织厂的大门"（进厂年份 = 1963）
2. "三年后，当周厚生……被下放到邻县农具厂的那个寒冷冬夜"（推得下放年份 = 1966）
3. "周厚生在临走前，依然像四年前她刚进厂第一天那样"（以下放年份反推，进厂年份 = 1966 − 4 = 1962）

引文一给出的进厂年份（1963）与引文三反推出的进厂年份（1962）不一致；更直接地说，"三年后"与"四年前"是对同一段时间（进厂到下放）的两种表述，三年 ≠ 四年。全文没有任何一处把这处差异归因为"记忆不确定"或"不同讲述者版本"——按 `criteria/02-continuity.md`「特殊框架：合法变异白名单」（差异须文本明确归因才能豁免），这不满足豁免条件，是**确证矛盾**。

对应判据：**C2**（年龄增长、旅程、等待与事件间隔在时间上可能成立），高严重度 NO。因未获文本内归因豁免，触发 `SKILL.md` §5.1 红线区规则——这与文学带单独判定的 C 各自独立成立，互相印证：一篇文本可以同时在"文学带"和"忠实/一致性红线"两条轴上出问题，两者不互相替代、也不互相掩盖。

### 三类缺陷在文中的位置

情感硬推集中在中段"心仿佛被狠狠揪了一下"到"泪水在她眼眶里决堤"这一句群；套话密集贯穿首尾（开篇"岁月如歌"、中段"值得注意的是""总的来说"、结尾"时代赞歌"）；时间线矛盾潜伏在"三年后"与"四年前"两处数字表述之间——不像前两类那样触目，更接近真实评审中容易被读快了漏掉的那类矛盾，提醒评审必须逐句核对每一个数字，不能因为文风已经明显有问题就跳过机械核验。

### 与其他带位的对照点

同一个告别场景，band-a 靠动作把情绪"呈现"出来，本篇靠形容词和感叹把情绪"宣布"出来——E1/E2 从 YES 到 NO 的分界线，就是"呈现"和"宣布"的分界线。同一个"临走教手艺"的动作，band-a 有具体到毫米级的技术细节（"这个结要打在纱线转过去的那一面"），本篇只有"仿佛要把毕生所学都倾囊相授"这种可以套用到任何师徒故事的空洞升华。
