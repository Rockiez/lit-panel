# 席位判据：05 人物与心理审读（lit-character）

**席位定位**：评估人物塑造与心理描写——动机连续性、对话口吻区分度、拒绝粉饰的真实人性；文学带核心席之一，core 判据任一 NO 即封顶 C。

**激活条件**：总是开席。

## core 判据表

| id | 极性 | 判据句 | 证据要求 | 溯源 |
|---|---|---|---|---|
| P1 | [通过] | 人物的行动、对白、目标与动机符合既建处境与性格；如有变化，存在可引证的触发点。 | 引文：该行动/对白/动机处 + 触发点（若判 NO，说明与既建性格的矛盾）。 | Rewarding Creativity·通用检查【已核实】 |
| P2 | [通过] | 人物通过语言、动作、神态或心理活动变得可辨认，而非只由叙述者贴性格标签。 | 引文：体现人物特质的具体描写（若判 NO，引出叙述者直接贴标签而无展示的句子）。 | EssayBench·人物塑造【已核实】 |
| P3 | [通过] | 心理活动有具体的感官、生理或动作细节支撑，而非仅用抽象词概括。 | 引文：该心理描写句；需指出其中的感官/生理/动作细节（若判 NO，指出其仅为抽象词，如"无比悲痛"）。 | 退稿标准·概念化空洞【二手待核】 |
| P4 | [通过] | 对话口吻体现说话者的身份、年龄与性格差异，不存在千人一腔。 | 引文：至少两位不同人物的对话，需说明口吻差异（若判 NO，说明二者可互换而不违和）。 | EssayBench + EQ-bench Weak Dialogue【已核实】 |
| P5 | [通过] | 自我或主要人物呈现了真实的人性弱点与挣扎，拒绝完美无瑕的粉饰。 | 引文：体现弱点/挣扎的段落（若判 NO，指出人物被塑造得完美无缺、无内在矛盾）。 | 回忆录指南·Anti-Hagiography【二手待核】 |
| TW13 | [通过] | 每个人物有恰当复杂度，没有纯情节工具人。 | 引文：涉及该人物的段落；需说明其复杂度（若判 NO，指出该人物仅为推动情节而存在，无独立动机或视角）。 | TTCW#13 Character Development【已核实】 |

## 判定提示

1. core 判据（P1-P5、TW13）任一 NO 即封顶文学带 C，判定时不因情节精彩而放宽人物塑造的严格度。
2. P3 的"抽象词概括"是常见失分点，判定时优先找心理描写句里有没有可触摸的感官/动作细节，而非仅凭情绪强度词判断。
