# 判据文件变更记录

> 本文件仅记录历史设计演变，不是运行时规则。当前唯一规范是 `SKILL.md` v0.6.1、schema 与机械脚本；旧版本中的顺序模拟和旧章节号均已作废，v0.4.1 评分公式在 v0.5.2 重新纳入正式合同，在 v0.6.0 被 formula 0.5.0-anchored 取代，并在 v0.6.1 被 formula 0.6.0-band-anchored 进一步修正。

## v0.6.1（评分公式 formula 0.6.0-band-anchored——双重惩罚修复，带位锚定分数）

**本条记录例外说明**：与 v0.6.0 相同的边界——本版**不改动任何一条判据的语义、极性或 core/extended/veto 归属**，craft set 成员（04:N3/TW2/TW4/SC1、05:P2/P3/P4/P7、06:L5/L7/TW3、07:E3/E6/E7/TW14）判据句、极性与证据要求逐字未变。改动全部落在评分/带位导出层（`derive_report.py`、`SKILL.md` 第 7/7.1 节），本条记录只是在判据文件时间线上留一个锚点。

**背景**：「方案乙实施契约」（2026-08-26 定稿，18 篇 codex 活体评审 + 3 篇 claude 交叉校验）确认文学带层健康——88.9% 精确带位一致、零 ≥2 档偏差、两模型家族问题计数高度一致——但 v0.6.0 的分数层语义被证实是坏的：craft/excellence 判据被双重惩罚，一次是所在维度的 craft_ratio 加分缺席，一次是同一维度的普通 core 扣分账本把该缺席也计入扣分对象；又因为多数核心/extended 判据本身是卓越标记而非缺陷，一篇称职但平实的文本会合法未通过约 44% 判据，17 项核心问题 × −12 累积的扣分预算远超 0–100 量纲，分数触底饱和、停止携带信息。

**实证依据**（18 篇 codex 活体评审，可复算，见「方案乙实施契约」表）：

| 档 | craft 比例 | 非 craft 缺陷密度 | 高severity veto |
|---|---|---|---|
| S/A | 0.87–1.00 | 0.00 | 0 |
| B | 0.33–0.53 | 0.09–0.27 | 0 |
| C | 0.00–0.27 | 0.30–0.61 | 0–1 |
| F | 0.00–0.13 | 0.45–0.64 | 2–3 |

craft 比例以 0.30 / 0.60 两条线完全分开三档，无重叠——这是本版把 craft 天花板设为独立于缺陷天花板的第二条带位判据的实证基础。

**评分/带位层改动**（不在本文件范围，供交叉参考，详见 `derive_report.py`、`SKILL.md` 第 7/7.1 节变更记录）：分数不再独立导出，而是**带位的可读投影**。文学带取两条独立天花板中更严格者：craft 天花板（每核心席 craft_ratio ≥0.6 → A；否则 craft_overall ≥0.3 → B；否则 → 记录型）与缺陷天花板（沿用既有红线不变：高严重度 veto → C；其他 veto/core → B；否则 → A）；`literary_band()` = min(缺陷天花板, craft 天花板)。分数窗口 A/A候选 `[85,94]`、B(非记录型) `[75,84]`、B(记录型) `[68,74]`、C `[45,59]`；判据向量只负责窗口内定位（`p = 0.7×核心席加权平均 p_i + 0.3×min(p_i)`，`p_i = 0.5×craft_ratio_i + 0.5×(1−defect_density_i)`，叠加原创性 +0.05/+0.03 与 lit-slop −0.02/累计−0.10 调整后 clamp 到 `[0,1]`；`total = lo + (hi−lo)×p`）。craft set 成员从此**只通过 craft_ratio 贡献正向证据，缺席只是不加分，不再二次扣分**——这是本版的核心语义修正。机械带位封顶于 A；`S`（传世）判据向量无法与 `A` 区分（两者 craft_ratio 均落在 0.87–1.00），保留为人工典藏裁定，不由公式产生，`[95,100]` 仅存在于文档。忠实度封顶（B→75、C→45）在窗口投影之后最后应用，可合法把总分推出所在窗口。

**常数标注**：`0.6`/`0.3`（带位门）、`0.5`/`0.5`（craft 与缺陷权重）、`0.7`/`0.3`（均值与短板）、`0.05`/`0.03`（原创）、`0.02`/`0.10`（slop）、四个分数窗口，全部标注为 **provisional**，来源为 2026-08-26 的 18 篇锚文活体校准（codex 主评，3 篇 claude 交叉），模型版本与语料快照记入提交信息，后续校准应更新记录而非静默漂移。

**溯源与决策记录**：完整方案见「方案乙实施契约」S1（带位两天花板）、S2（分数窗口）、S3（带内定位）、S4（常数标注）；该契约取代 v0.6.0 所依据的 `lit_eval_redesign` V3 方案在评分层的具体公式，不改变 V3 已发布的逐席 craft 门（此契约称为「craft 天花板」）。

## v0.4.1（席09原创性退出veto/带位路径，改纯加分——O1 veto身份撤销）

**语义变更**：席09（原创性与陈套审读）不再参与文学带 veto/扣分/封顶——文学带核心判据集自本版起收窄为席04/05/06/07（结构/人物/语言/情感）。O1（"拒绝被用滥的比喻/场景模板/感悟句式"）v0.2.0 起被划为本席 veto，本版**撤销其 veto 身份，降回普通 core 判据**——不再单列"veto 判据表"小节，命中不再触发带位封顶。本席评审工作流、判定+引文+自由观点要求、输出契约逐字未变，只是判定结果的**去向**改变：从"驱动带位封顶"改为"驱动 `SKILL.md` §5.8 原创加分"（O 系通过类判据 O2/O3/O5/O6 全部 YES 且零问题判定 → 总分 +5；≥3 条 YES 且零问题判定 → +3；其余含任何问题判定 → +0，任何情况下不扣分）；问题判定降级为报告"问题与修订建议"区的可选打磨建议，不静音、不消失，只是不再具备封带能力。

**理由——回忆录域产品立场：原创性是锦上添花，非欠账**：lit-panel 的评审对象是 AI 生成的中文回忆录/口述史文本，这类文本的首要产品价值是**忠实记录一段真实人生**，原创性（转折是否出人意料、比喻是否新颖、讲法是否有个性）是文本读起来更好看的加分项，而不是回忆录这个体裁的核心义务——一段平实、甚至略显套路化讲述的真实人生经历，仍然是合格、有价值的回忆录；反过来，即便文笔处处新颖，若忠实度或结构/人物/语言/情感这些叙事基本功出了问题，才是真正的"欠账"。v0.2.0 曾把 O1 划入 veto、与结构/人物/语言/情感的 veto 判据同等对待，隐含的假设是"原创性欠缺=结构性坍塌"，这个假设对回忆录体裁不成立——套路化的比喻或感悟句式最多是"这段话不够出彩"，从未达到"叙事根基不可信"的严重程度，不应该和"无因之果""动机断裂""声音失控""情感硬推/未被戏剧化"这类真正代表文本结构性坍塌的问题共享同一套封顶后果。本版把原创性从"扣分/封带"路径挪到"加分"路径，是把评分体系的严厉程度与这一体裁的实际产品价值排序对齐——原创性好是惊喜，原创性平淡不是事故。

**影响范围**：`SKILL.md`（§5.3 带位规则、§5.8 评分导出公式）、`registry.md`（09 行带位角色、预设分档说明）、`criteria/09-originality.md`（本文件，veto 小节撤销）、`agents/originality-reviewer.md`（v0.2.0 带位表述改写）、`references/anchors/`（band-a/b/c 三文件的核心判据论证同步撤除 O1 的 veto 承重角色）、`README.md`、`docs/DESIGN.md`。判据句本身（O1-O6 判据文字、极性、证据要求）**逐字未改**，仅带位/评分归属层变更。

## v0.4.0（报告层全面重构 + 评分导出层——不改判据文件本身）

**本条记录例外说明**：与本文件通常的"判据文件变更记录"范围不同，v0.4.0 **不改动任何一条判据的语义、极性或 core/extended/veto 归属**——11 个 `criteria/*.md` 文件、`agents/*.md` 的输出契约字段（verdict/quote/location/severity/note）逐字未变。之所以仍在此记录一节，是为了在判据变更时间线上留一个明确的"此版本判据层无变化"的锚点，避免后续读者误以为版本号跳到 v0.4.0 意味着判据也跟着改了。

**这一版实际改了什么**：报告输出层（`report-template.md` 完全重写为总评/红线警报/总分卡/多维评分表/评委分论/问题与修订建议/需人工裁决/评审档案八区块的新结构，区块标题不带编号、物理顺序即阅读顺序；全量判据表移出主报告进 `<报告名>-details.md` 侧车，v0.4.0 微调（6b）起需人工裁决区也全面禁表格、改叙述文风，原始表格同样进侧车）+ 新增评分导出层（`SKILL.md` §5.8，判据向量按公开确定性公式机械导出 0-100 分：文学五维、AI洁净度、读者体验、忠实度、总分）。分数是判据向量的**视图**，不是评审席的**判断**——这条边界是本轮设计的核心约束，贯穿 `SKILL.md` §5.8/§5.9、`report-template.md` 顶部使用说明、`README.md`"分数从哪来"。

**为什么现在加分数**：此前三轮（v0.2.0–v0.3.0）的实测与摩擦日志显示，带位（A/B/C）对使用者足够但不总够——三档定性归类在同一档内仍会跨度很大（同是"B"的两篇文本，一篇只差一条 veto 中严重度问题、另一篇有五条 extended 问题，读者从带位本身看不出这个差异），而多维评分表能在不引入"总分幻觉"的前提下把这层粒度露出来，代价是必须守住"分数从判据向量机械导出、评审席不产生数字"这条线，不能滑回"模型自己打分"的老路。

## v0.3.0（A7 条件激活 + NA 仲裁降级——第五轮性能优化里唯二触及判据层的改动）

本版是第五轮性能优化（目标：砍掉过度防御与顺序路径的重复成本，把 Codex `standard` 顺序评审耗时从约 40 分钟压向 15–20 分钟）里**唯二**改动判据文件本身语义的项目；同一轮的其余改动（quote 引证义务分级、顺序路径正文单贴、锚点惰性加载、`--fast-compare`）都在 orchestrator/契约层，不改变任何判据句的语义或极性，不记入本文件——细节见 `SKILL.md`、`agents/*.md`、`docs/DESIGN.md` 的对应改动。

**本轮共同的实证背景**：六轮真机执行与摩擦日志累计下来，被评审产出的逐字引文总数已超过 150 条，核验管道从未在其中拦下过一条"自然作废"的引文（即评审席自己正常作答时产出、查无此文的引文；不含人为篡改测试用途的引文）——这说明"每条判定都必须附引文"这条此前的强制要求，对已经能稳定输出真实引文的评审席而言，绝大多数时候只是重复劳动，没有对应的错误拦截收益（防捏造的价值仍然成立，只是没有必要覆盖到通过判定这一类）。这项证据是本轮 quote 引证义务分级（契约层改动，见 `SKILL.md` §3.4）的主要依据；下面两条判据层改动分别对应另一类独立的噪声证据。

### A7（席03）从"单章记 NA"改为条件激活

A7（"与其他章节相比异常复用同一批感官短语、强化词或描写搭配"）此前的处理是：单章评审时一律记 NA。v0.3.0 起改为**条件激活**——仅当本轮提供跨章语料时，A7 才进入判据集；单章评审时 A7 不出现在判据表、判据向量或报告任何区块，不再走"记 NA"这条路径。

**理由**：迄今全部真机测试与摩擦日志覆盖的场景都是单章评审，A7 在这个场景下永远只有一种可能结果——NA 判定不携带任何诊断信息，却仍占用一整条判据表行、一次席位作答，v0.2.0 规则下还会额外占用一次人工仲裁区扫描。把"必然发生的空判定"从判据集里移除，比让它照常发生再记 NA 更省成本，也更诚实——A7 本来就不该出现在单章评审的判据集范围内，"记 NA"只是在假装它被评审过。

### NA 仲裁降级：仅 veto 判据的 NA 才进人工仲裁区

v0.2.0 规则：veto 或 core 级判据的 NA（无论是否附适用性理由）一律列入报告人工仲裁区。v0.3.0 起收窄为：**仅 veto 判据的 NA**（附适用性理由；无理由的 NA 仍按既有规则降级为 ABSTAIN，归入 ABSTAIN 类）进人工仲裁区——普通 core/extended 判据的 NA（带理由）正常呈现在分席判据表，不升级到仲裁区。

**理由**：六轮真机与摩擦日志实测显示，每轮评审平均出现 3–6 条前提缺失型 NA（如某判据的证据要求依赖 `--source`/`--brief`/跨章语料等本轮未提供的前置输入，判据本身合理但本轮条件不满足）。这类 NA 附带的适用性理由已经在分席判据表里说明了"为什么不适用"，送进人工仲裁区不产生新的判断增量——真正需要人工复核的是"判断本身是否应该缺失"这件事，这只对 veto 判据成立，因为 veto 的 NA 意味着带位判定的一个直接输入不存在；普通 core/extended 判据即使出现几条 NA，也不改变带位判定的结论路径。仲裁区收窄后，人工复核的注意力集中在真正影响带位结果的缺失上，不被前提缺失型噪声稀释。

### veto 判据分级（文学带核心席 04/05/06/07/09）

在既有 core/extended 二层之上，从五席核心判据表内各自划出 ≤2 条升格为 **veto** 层——veto 是 core 判据中最不可辩护、命中即代表该维度结构性坍塌的子集（选择标准：不是最常用的判据，是命中后果最致命的判据）。带位后果差异见各文件"veto 判据表"标注、SKILL.md §5.3。逐席选择与理由：

- **席04（结构）→ N2（无因之果）**：候选还包括 N1（被遗弃的情节承诺）与 N4（流水账式罗列，缺"动机-阻碍-行动-结果"循环），但 N2"重大结果无铺垫无解释"是叙事因果链最基础的断裂点——读者连"为什么会这样"都无法理解，比"某条线索没收尾"（N1）或"叙事引擎偏弱"（N4）更直接摧毁对整篇叙事逻辑的信任。只选 1 条，未凑满 2 条上限。
- **席05（人物）→ P1（行动/动机与既定处境性格一致）**：候选还包括 P5（拒绝粉饰）与 P3（抽象概括代替具体细节），但 P1 是人物写作的地基——一旦某个行动/动机毫无触发点地偏离既定性格，读者会对文本里**所有**人物刻画的可信度产生连锁怀疑，而 P5/P3 更多是深度/技法问题，不会牵连全篇。只选 1 条。
- **席06（语言）→ L1（声音/语域随场景解释）**：候选还包括 L2（词汇句法变化需意图），但 L1（语调/人物声音无来由的突变）比 L2（词汇句法层面的拼接感）更容易让读者直接察觉"这是谁在说话"的错乱，是声音一致性里最先失控、也最难挽回的一层。只选 1 条。
- **席07（情感）→ E1（情绪由行动/对白/环境承载）+ E2（拒绝情感硬推）**：本席是唯一选满 2 条的核心席——E1（情绪完全没被戏剧化，只被叙述者宣布）与 E2（情绪被强行戏剧化到失真）恰好是"processed vs lived"这一失败空间的两个对称极端，且本席自己的席位定位一句话（"processed vs lived 的平衡、避免情感硬推"）本就同时点名了这两端，任一极端命中都代表本章情感处理从根本上失败，两条缺一不足以覆盖整个失败面。
- **席09（原创性）→ O1（拒绝被用滥的比喻/场景模板/感悟句式）**：候选还包括 O2（独特见解）与 O3（转折意外合理），但 O1 命中意味着"这段话可能出自任何一篇同类文本"，直接击穿"原创"这个维度的存在理由；O2 关乎见解的**价值**而非表达的**新鲜度**，O3 关乎情节机关（且与 TW8 有交叠，见下方重叠审计），严重度都不如 O1 直接。只选 1 条。
