# 席位判据：09 原创性与陈套审读（lit-originality）

**席位定位**：评估原创性与陈套——人类写作意义上的套路与平庸、意外而合理的转折、个性化的讲述方式；文学带核心席之一。判据分三层（veto/core/extended，见 SKILL.md §5.3 带位规则）：veto 判据的问题判定且严重度=高 → 封顶 C；veto 问题判定但严重度=中/低，或其余 core 判据任一问题判定 → 最高封顶 B。

**激活条件**：总是开席。

## 特殊框架：与席03的分工边界

席03（AI 痕迹猎手）与本席都可能标记"套话"，但诊断的层面不同，两者判定互不替代、可对同一处文本各自独立命中：

- **席03**：抓 **AI 特有**的机械痕迹——可对照模式库做 span 匹配的填充、模板化起承转合、复述、翻译腔（见 slop-patterns-zh.md）。这类问题即使换一个不同措辞，仍会因结构雷同被模式库捕捉。
- **本席**：抓 **人类写作意义上**的陈词滥调与平庸——即便一句话写得通顺、不带 AI 腔调，但若是"苦难—奋斗—感恩"式的套路选材、被用滥的比喻、可预期的转折，依然要在本席判 NO/风险命中。判定时不参考模式库，凭文学判断力评估"这段话/这个转折是否似曾相识"。

同一处文本被两席同时标记不算重复计分——orchestrator 按席归组列出判据向量，两条判定各自独立生效（见 `skills/lit-panel/SKILL.md` §5.2）。

## 判定提示

1. **veto 判据（O1）**：命中（YES，风险极性）时必须给出严重度，直接决定带位分支——高严重度 → C；中/低严重度 → 最高封顶 B 并额外进入报告的人工仲裁区复核（见 SKILL.md §5.3）。判严重度看该比喻/模板句式的陈旧程度与其在文中的分量（贯穿全篇的核心比喻 → 高；一两处装饰性套语 → 中/低）。
2. **其余 core 判据（O2、O3）**：任一 NO 即最高封顶文学带 B（不再触发 C）。
3. 判定 O1/O4 时不查 slop-patterns-zh.md（那是席03 的工具），凭文学阅读经验判断"这是否似曾相识"；如拿不准是 AI 痕迹还是人类套路，两席都可各自独立标记，不必互相排除。
4. **O3 与席04 TW8 的边界**（v0.2.0 重叠审计发现，见 `criteria/CHANGELOG.md`）：两者都在问同一个转折"是否意外、是否合理"，但取证侧重不同——O3（本席）只评估转折**类型本身**新不新颖：是否落入"其实早已知情""巧合揭示身世""命运殊途同归"这类高频反转公式；这个转折在结构上有没有伏笔支撑、逻辑是否自洽，不在本判据评估范围，那是席04 TW8 的职责。同一转折两席仍可各自独立判 YES/NO，不因对方已判而省略。
