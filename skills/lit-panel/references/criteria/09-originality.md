# 席位判据：09 原创性与陈套审读（lit-originality）

**席位定位**：评估原创性与陈套——人类写作意义上的套路与平庸、意外而合理的转折、个性化的讲述方式；**加分席**（v0.4.1 起）：本席发现的亮点决定总分加分，问题判定作为可选打磨建议输出，不参与扣分与带位（机械规则见 SKILL.md §5.8"原创加分"）。本席评审工作流、判定+引文+自由观点要求不变——只是判定结果自 v0.4.1 起不再进入文学带 veto/扣分路径，文学带核心判据集收窄为席 04/05/06/07。

**激活条件**：总是开席。

## 特殊框架：与席03的分工边界

席03（AI 痕迹猎手）与本席都可能标记"套话"，但诊断的层面不同，两者判定互不替代、可对同一处文本各自独立命中：

- **席03**：抓 **AI 特有**的机械痕迹——可对照模式库做 span 匹配的填充、模板化起承转合、复述、翻译腔（见 slop-patterns-zh.md）。这类问题即使换一个不同措辞，仍会因结构雷同被模式库捕捉。
- **本席**：抓 **人类写作意义上**的陈词滥调与平庸——即便一句话写得通顺、不带 AI 腔调，但若是"苦难—奋斗—感恩"式的套路选材、被用滥的比喻、可预期的转折，依然要在本席判 NO/风险命中。判定时不参考模式库，凭文学判断力评估"这段话/这个转折是否似曾相识"。

同一处文本被两席同时标记不算重复计分——orchestrator 按席归组列出判据向量，两条判定各自独立生效（见 `skills/lit-panel/SKILL.md` §5.2）。

## 判定提示

1. **本席判定不触发带位封顶（v0.4.1 起）**：O1 命中（YES，风险极性）与其余 O 系问题判定，均不再使文学带封顶 C 或 B——文学带核心判据集自 v0.4.1 起收窄为席 04/05/06/07。本席全部判定改走 SKILL.md §5.8"原创加分"机械规则：O 系通过类判据（O2/O3/O5/O6）全部 YES 且零问题判定 → 总分 +5；≥3 条 YES 且零问题判定 → +3；其余（含任何问题判定，无论 severity）→ +0，**任何情况下不扣分**。问题判定（含 O1 命中）仍需按 3.4 节输出契约照常填写 severity + 修改建议——severity 不再决定带位分支，但仍用于报告"问题与修订建议"区的排序依据，不因带位职能取消而省略。问题判定作为可选打磨建议进报告，不进红线区、不进人工仲裁区的 veto 复核类目。
2. 判定 O1/O4 时不查 slop-patterns-zh.md（那是席03 的工具），凭文学阅读经验判断"这是否似曾相识"；如拿不准是 AI 痕迹还是人类套路，两席都可各自独立标记，不必互相排除。
3. **O3 与席04 TW8 的边界**（v0.2.0 重叠审计发现，见 `criteria/CHANGELOG.md`）：两者都在问同一个转折"是否意外、是否合理"，但取证侧重不同——O3（本席）只评估转折**类型本身**新不新颖：是否落入"其实早已知情""巧合揭示身世""命运殊途同归"这类高频反转公式；这个转折在结构上有没有伏笔支撑、逻辑是否自洽，不在本判据评估范围，那是席04 TW8 的职责。同一转折两席仍可各自独立判 YES/NO，不因对方已判而省略。
